# Executive Summary

The **Smart Hybrid Library Management and Automation System (SHLMAS)** is a proposed library circulation management system designed to improve the efficiency, accuracy, and accessibility of school library operations through workflow automation and centralized digital management.

Many secondary school libraries continue to rely on handwritten logbooks or spreadsheet-based record keeping for borrowing and returning books. While these traditional methods remain functional, they often result in slow transaction times, inaccurate inventory records, misplaced books, delayed report generation, and increased workload for librarians. Students also experience difficulty determining book availability before visiting the library, while librarians spend considerable time performing repetitive administrative tasks.

To address these challenges, this study proposes the development of SHLMAS, a hybrid ecosystem that combines both software and hardware components into a unified library management solution. The proposed system integrates a **web-based student portal**, a **self-service borrowing kiosk**, a **smart return box**, a **centralized database**, and a **librarian analytics dashboard** to automate key library circulation processes while maintaining librarian supervision and administrative control.

Unlike conventional Library Management Systems that primarily digitize paper records, SHLMAS focuses on redesigning the entire borrowing and returning workflow. Students can search for books, check availability, reserve materials, and review their borrowing history through the student portal. Borrowing transactions are completed through a self-service kiosk using QR code authentication, while returned books are processed automatically through a smart return box that updates the inventory database in real time. Librarians retain the ability to monitor transactions, manage inventory, approve special borrowing requests, and generate operational reports through a centralized dashboard.

The system primarily utilizes **QR code technology** because it provides an affordable, reliable, and easily deployable solution for secondary schools without requiring expensive infrastructure. The modular system architecture also supports future upgrades, including RFID integration, mobile applications, and cloud synchronization, without requiring significant redesign.

The primary objective of this research is to determine whether implementing the Smart Hybrid Library Management and Automation System can significantly improve the efficiency and accuracy of library circulation compared to the existing manual process.

To evaluate the effectiveness of the proposed system, the researchers will measure several performance indicators before and after implementation, including:

- Average borrowing transaction time
- Average return processing time
- Library inventory accuracy
- Number of overdue books
- Number of lost books
- Librarian workload
- User satisfaction
- Overall system usability

Data will be collected through transaction logs, direct observations, and survey questionnaires administered to students, librarians, and teachers. The collected data will then be analyzed to determine whether the implementation of SHLMAS produces statistically significant improvements in library operations.

The researchers expect that SHLMAS will reduce manual workload, improve inventory management, minimize borrowing errors, simplify book circulation, and provide a more convenient library experience for students while offering librarians better monitoring, reporting, and decision-making tools.

Ultimately, this study aims to demonstrate that integrating affordable automation technologies with a modular hybrid library management system can provide a practical, scalable, and cost-effective solution for modernizing school libraries and improving the overall quality of library services in educational institutions.
