# Research Methodology

## Research Design

This study employs a **Research and Development (R&D)** approach combined with a **Quantitative Descriptive-Evaluative Research Design**.

The Research and Development approach is appropriate because the study involves designing, developing, implementing, and evaluating a functional software and hardware system.

After the development of the Smart Hybrid Library Management and Automation System (SHLMAS), quantitative evaluation will be conducted to determine whether the system significantly improves library circulation compared to the existing manual process.

The study follows four major phases:

1. System Planning
2. System Development
3. System Implementation
4. System Evaluation

---

# Development Methodology

The researchers will follow the **Agile Software Development Methodology**.

Agile was selected because it allows continuous testing, improvements, and feedback throughout the development process.

The development cycle consists of:

```
Planning
      ↓
System Design
      ↓
Development
      ↓
Testing
      ↓
Evaluation
      ↓
Improvement
      ↺
```

This iterative process enables the researchers to continuously improve SHLMAS based on testing results and user feedback.

---

# Research Locale

The study will be conducted in the selected secondary school's library where the existing manual library circulation system is currently implemented.

The library will serve as the testing environment for evaluating the effectiveness of SHLMAS.

---

# Respondents of the Study

The respondents of the study include:

- Students
- Librarians
- Teachers

Students will evaluate the usability of the Student Portal and Borrowing Kiosk.

Librarians will evaluate inventory management, reporting, and administrative functions.

Teachers will evaluate the usefulness of monitoring reports and overall system effectiveness.

---

# Sampling Technique

The study will use **Purposive Sampling**.

Respondents will be selected based on their direct involvement in library activities.

The researchers may include:

- Students who frequently borrow books
- School librarians
- Teachers who utilize library resources

---

# Research Instruments

The following instruments will be used to collect data:

## 1. User Satisfaction Questionnaire

Measures:

- Ease of use
- Interface design
- Reliability
- Efficiency
- Overall satisfaction

A 5-point Likert Scale will be used.

Example:

| Rating | Interpretation |
|---------|---------------|
| 5 | Strongly Agree |
| 4 | Agree |
| 3 | Neutral |
| 2 | Disagree |
| 1 | Strongly Disagree |

---

## 2. Observation Checklist

Researchers will observe:

- Borrowing procedures
- Returning procedures
- Inventory updating
- User interaction
- Librarian workflow

---

## 3. Time Measurement

The researchers will record:

- Borrowing time using the manual system
- Borrowing time using SHLMAS

- Returning time using the manual system
- Returning time using SHLMAS

These values will be compared to determine efficiency improvements.

---

## 4. System Logs

The system automatically records:

- Borrowing transactions
- Returning transactions
- Overdue books
- Inventory changes
- User activities

These logs provide objective data for evaluation.

---

# Data Collection Procedure

The study will follow these steps:

## Phase 1 — Preparation

- Obtain approval from the school administration.
- Coordinate with the librarian.
- Prepare research instruments.
- Register books and users in the system.

---

## Phase 2 — Development

The researchers will:

- Develop the Student Portal.
- Develop the Librarian Dashboard.
- Develop the Borrowing Kiosk.
- Develop the Smart Return Box.
- Integrate all modules into one centralized database.

---

## Phase 3 — Testing

Researchers will perform:

- Unit Testing
- Integration Testing
- System Testing

Errors discovered during testing will be corrected before deployment.

---

## Phase 4 — Implementation

The completed system will be deployed in the selected library.

Students and librarians will use SHLMAS during actual borrowing and returning transactions.

---

## Phase 5 — Evaluation

The researchers will:

- Observe system usage.
- Record borrowing and returning times.
- Collect user satisfaction surveys.
- Compare manual and automated workflows.
- Analyze the collected data.

---

# Evaluation Criteria

The effectiveness of SHLMAS will be evaluated using the following indicators:

## Efficiency

Measured through:

- Average borrowing time
- Average returning time

---

## Accuracy

Measured through:

- Inventory accuracy
- Correct transaction recording
- Correct borrower identification

---

## Effectiveness

Measured through:

- Number of overdue books
- Number of misplaced books
- Number of completed transactions

---

## Usability

Measured using survey responses regarding:

- Ease of learning
- Ease of use
- User interface
- Overall satisfaction

---

# Statistical Treatment of Data

The collected data will be analyzed using descriptive statistics.

The following statistical tools will be used:

## Frequency

Used to determine:

- Number of transactions
- Number of overdue books
- Number of lost books

---

## Percentage

Used to compute:

- Inventory accuracy
- User responses
- Book availability

---

## Mean

Used to determine:

- Average borrowing time
- Average returning time
- Average satisfaction score

Formula:

Mean = ΣX / N

---

## Standard Deviation (Optional)

Used to determine the consistency of responses from respondents.

---

## Independent Samples t-test (Recommended)

To determine whether there is a statistically significant difference between:

- Manual library circulation
- SHLMAS library circulation

The significance level will be set at:

**α = 0.05**

If **p < 0.05**, the null hypothesis will be rejected.

---

# Ethical Considerations

The researchers will ensure that:

- Participation is voluntary.
- Respondents provide informed consent.
- Personal information is kept confidential.
- Survey responses remain anonymous.
- Data is used solely for academic purposes.

Only authorized librarians and researchers will have administrative access to the system.

---

# Success Criteria

The Smart Hybrid Library Management and Automation System will be considered successful if it demonstrates:

- Reduced borrowing time
- Reduced returning time
- Improved inventory accuracy
- Reduced overdue books
- Reduced misplaced books
- Positive user satisfaction
- Reliable synchronization between all modules

These indicators will determine whether SHLMAS significantly improves library circulation compared to the school's existing manual process.
